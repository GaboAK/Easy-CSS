2 BOX #2 • FUNDAMENTO ESENCIAL

¿Qué es una pseudoclase CSS?

Las pseudoclases se utilizan para hacer referencia a elementos HTML que tengan un cierto comportamiento concreto. Mientras los selectores clásicos apuntan a etiquetas o clases fijas en el código, las pseudoclases permiten seleccionar elementos que en principio parecen idénticos, pero presentan diferentes características de comportamiento en el navegador.

Notación con dos puntos simples (:) Respuesta a acciones del usuario Selección por estructura y estados Sin necesidad de JavaScript
3

BOX #3 • Sintaxis General

Regla CSS

En el esquema de sintaxis de CSS, las pseudoclases se definen añadiendo dos puntos (:) antes del nombre de la pseudoclase concreta, colocada inmediatamente tras el selector o etiqueta sin dejar espacios:

selector:pseudoclase { propiedad: valor; }

De esta forma podemos aplicar estilos específicos únicamente cuando el elemento entra en un estado concreto (pulsado, enfocado, deshabilitado o situado en una posición específica del documento).

Diferencia clave: Las pseudoclases usan : (un solo par de puntos), mientras que los pseudoelementos usan :: (doble dos puntos).
4

BOX #4 • Ejemplo Práctico

:hover

La pseudoclase más popular y elemental explicada en LenguajeCSS es :hover. Indica al navegador que dé estilo cuando el usuario posicione su ratón o dispositivo apuntador sobre el elemento: 

a { padding: 5px; }
a:hover {
  background: red;
  color: white;
  text-decoration: none;
}
  • El enlace siempre tendrá un padding base de 5 píxeles.
  • Tendrá fondo rojo, texto blanco y sin subrayado exclusivamente al pasar el ratón por encima.
A continuación, exploramos los tipos y categorías de pseudoclases documentadas en LenguajeCSS.
5 BOX #5
Interacción
:hover
Puntero Encima

Se activa cuando el usuario coloca el ratón o dispositivo apuntador sobre el elemento sin necesidad de hacer clic.

Uso: Botones, tarjetas y enlaces.
6 BOX #6
Interacción
:active
Elemento Pulsado

Representa el estado exacto en el que el usuario hace clic y mantiene presionado el botón del ratón sobre el elemento.

Uso: Efecto de botón presionado.
7 BOX #7
Interacción
:focus
Foco de Entrada

Selecciona el elemento que tiene el foco activo, ya sea por clic o al navegar mediante la tecla Tabulador.

Uso: Resaltar campos de formulario.
8 BOX #8
Interacción
:focus-within
Foco en Descendiente

Se activa sobre un contenedor padre cuando dicho contenedor o cualquiera de sus elementos hijos recibe el foco.

Uso: Iluminar un formulario entero.
9 BOX #9
Interacción
:focus-visible
Foco Accesible

Aplica indicador de foco solo cuando el usuario navega con teclado, evitando marcos toscos al hacer clic con ratón.

Uso: Accesibilidad sin romper diseño.
10 BOX #10
Ubicación
:link / :visited
Enlaces y Visitas

:link selecciona hipervínculos no visitados; :visited selecciona aquellos que el usuario ya ha abierto en su historial.

Uso: Señalización de enlaces leídos.
11 BOX #11
Ubicación
:target / :any-link
Ancla de la URL

:target apunta al elemento cuyo identificador coincide con el hash (#) de la URL actual. :any-link agrupa todo enlace con href.

Uso: Modales y pestañas con CSS.
12 BOX #12
Idioma
:lang() / :dir()
Idioma y Dirección

:lang() selecciona elementos según el idioma (ej. :lang(es)). :dir() detecta la dirección del texto (ltr o rtl).

Uso: Sitios multilingües y citas.
13 BOX #13
Estructura
:root
Elemento Raíz

Selecciona el elemento raíz del árbol HTML. Posee mayor especificidad que la etiqueta html y es el hogar de variables CSS.

Uso: Variables globales (:root { ... }).
14 BOX #14
Estructura
:empty
Contenedor Vacío

Selecciona elementos que no tienen ningún hijo, texto o nodo en su interior (ni siquiera espacios en blanco).

Uso: Ocultar alertas sin mensajes.
15 BOX #15
Estructura
:first/last-child
Extremos de Hermanos

:first-child selecciona el primer elemento hijo de su contenedor padre; :last-child selecciona el último de ellos.

Uso: Quitar bordes a ítems de lista.
16 BOX #16
Estructura
:nth-child()
Patrones y Fórmulas

Selecciona elementos por fórmulas numéricas (an+b), índices exactos o palabras clave como pares (even) e impares (odd).

Uso: Tablas con filas tipo cebra.
17 BOX #17
Formulario
:checked
Casilla Marcada

Se aplica a elementos de tipo radio, checkbox u opciones de select que se encuentren activadas o seleccionadas.

Uso: Conmutadores y toggles custom.
18 BOX #18
Formulario
:enabled / :disabled
Disponibilidad

Discrimina entre elementos interactivos que están activos (:enabled) frente a los bloqueados con disabled (:disabled).

Uso: Atenuar botones bloqueados.
19 BOX #19
Formulario
:valid / :invalid
Validación Nativa

Evalúa en vivo si el contenido introducido por el usuario cumple con las reglas del campo (como type="email" o minlength).

Uso: Bordes verdes o rojos dinámicos.
20 BOX #20
Formulario
:required / :optional
Obligatoriedad

Selecciona campos que poseen el atributo required obligatorio frente a aquellos campos prescindibles u opcionales.

Uso: Señalización de campos mandatorios.
21 BOX #21
Formulario
:placeholder-shown
Placeholder Visible

Se activa cuando el texto de guía del input sigue visible, señalando que el usuario todavía no ha escrito nada.

Uso: Etiquetas flotantes (floating labels).
22 BOX #22
Estado y Paginado
:fullscreen / :modal
Pantalla y Modales

:fullscreen detecta elementos en pantalla completa; :modal selecciona diálogos dialog abiertos en capa superior nativa.

Uso: Reproductores y ventanas de diálogo.
